# Gift Charitable Trust — Gift.ngo

Website for Gift Charitable Trust.

## Positioning
**A Gift Today. A Better Tomorrow.**

Gift mobilizes contributions and supports charitable trusts, NGOs, community initiatives and people facing genuine needs.

The website distinguishes clearly between:
- **Current work:** support, contributions, partnerships and documented impact stories.
- **Future vision:** women's care centers, a free multispecialty mission hospital, and education support.

## Privacy
Beneficiary names are intentionally anonymized in public-facing stories (Student 1, Family 1, Beneficiary 1, etc.).
